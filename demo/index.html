佐藤建業様にデモを作らなかった理由

調査の結果、株式会社佐藤建業様には稼働中の公式サイト（sato-kengyo.com）が存在していました。従業員40名規模の会社に対して、いきなり「作り直し案」を送るのは失礼にあたります。

そのかわり、蔵王町商工会の会員ページに掲載されている旧ドメイン w-home.club が第三者に取得され、無関係な英語ニュースサイトになっている件を「ご報告」としてお伝えする形にしています。売り込みではなく、お知らせとして送ります。

送るときの手順

  1. 送る直前に、該当のデモURLをスマートフォンで実際に開いて表示を確認する
  2. 先方の公式サイトに「営業メールお断り」の記載がないか確認する
  3. 1日に送るのは3〜5通まで。まとめて送らない
  4. 返信がなくても追いかけない
  5. 「掲載をやめてほしい」と言われたら、その場で即削除する

各デモに入れてある安全措置

  1. ページ最上部に、かわたれ studio 制作である旨と公式サイトへのリンクを常時表示
  2. 検索エンジンに登録されない設定（noindex, nofollow, noarchive）
  3. robots.txt で /demo/ 以下をクロール対象外に指定
  4. 先方の写真・ロゴは一切使用せず、すべて手描きの図形と文字のみ
  5. フッターに、公開情報にもとづく提案であること・依頼があれば即削除する旨を明記
